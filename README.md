# New Beginnings Transitional Living Foundation

Production website for New Beginnings Transitional Living Foundation, a Pittsburgh 501(c)(3) recovery-housing nonprofit.

## Commands

```bash
npm install
npm run dev
npm run build
npm run predeploy-check
```

The site builds statically to `dist/` for deployment to Cloudflare Pages.

## Privacy

Do not add recovery-residence street addresses, maps, identifiable exterior photographs, or sensitive resident information. Public location copy is limited to neighborhood-level descriptions.
